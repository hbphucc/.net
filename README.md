# FashionShop – E-commerce Website
## Project Overview
The Fashion Shop project is a comprehensive online fashion retail system, modern Decoupled Architecture (completely separating the Frontend and Backend). The project utilizes ASP.NET Core Web API for business logic processing and a Vanilla JavaScript SPA for the user interface.
## Tech Stack
- Backend: C# (.NET 8), ASP.NET Core Web API, Entity Framework Core.
- Database: SQL Server.
- Security: JWT (JSON Web Token) for Authentication and role-based Authorization (Admin/User).
- Frontend: HTML5, CSS3 (Custom variables, Responsive Design), Vanilla JavaScript (ES6+), Fetch API.
- Architecture: Repository Pattern, DTO (Data Transfer Object), Dependency Injection.
## Key Responsibilities & Achievements:
- Designed and implemented RESTful APIs using ASP.NET Core and Repository Pattern to handle complex business logic for orders and inventory.
- Developed a secure authentication system using JWT, implementing role-based access control for Admin and Customer portals.
- Built a dynamic frontend using Vanilla JavaScript and Fetch API, managing state via LocalStorage to reduce server load and enhance user experience.
- Implemented an Admin Dashboard with real-time analytics for revenue and sales performance using LINQ and EF Core.
- Optimized database performance and ensured data integrity by validating prices and stock levels on the server side.
